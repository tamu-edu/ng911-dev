1.7. Nature of {% if io_mode %} Interoperability {% else %} Conformance {% endif %} Testing

{% if io_mode %} The purpose of Interoperability Testing is to increase confidence that different NG9-1-1 implementations can successfully inter-work across the interfaces, message exchanges, and operational scenarios exercised during testing. However, the complexity of NG9-1-1 protocols and system interactions makes exhaustive interoperability testing impractical on both technical and economic grounds. Furthermore, successful completion of the applicable test cases does not guarantee interoperability under all possible configurations, network conditions, or implementation combinations. Rather, the passing of the test cases provides confidence that the Implementation Under Test (IUT) can successfully interact with the participating NG9-1-1 Functional Elements in representative instances of communication. {% else %} The purpose of Conformance Testing is to increase the probability that different implementations can inter-work. However, the complexity of NG9-1-1 protocols makes exhaustive testing impractical on both technical and economic grounds. Furthermore, there is no guarantee that an Implementation Under Test (IUT) which has passed all the relevant test cases conforms to a specification. Neither is there any guarantee that such an IUT will interwork with other real open systems. Rather, the passing of the test cases gives confidence that the IUT has the stated capabilities and that its behavior conforms consistently in representative instances of communication. {% endif %}
